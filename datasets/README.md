# Datasets — SCIC PT Indoprima

Dummy supply chain datasets for development and testing.
Generated by scripts/generate_dummy_data.py.

## Directory Structure
- inventory/ — SKU master, stock levels, warehouse locations
- invoices/ — Invoice records, PO data, GRN data
- demand_history/ — 24-month demand history per SKU
- procurement/ — Supplier master, purchase orders, contracts
- erp_master/ — ERP reference data (item master, BOM, cost centers)
